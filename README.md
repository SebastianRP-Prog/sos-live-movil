# SOSLIVE

## Descripción

SOSLIVE es una empresa creada con el objetivo de proteger y brindar seguridad a las personas mediante el acompañamiento y monitoreo de un guarda de seguridad. Nuestro propósito es ofrecer una solución tecnológica moderna y eficiente que permita mejorar la seguridad y la tranquilidad de nuestros usuarios.

La plataforma está diseñada para facilitar la comunicación, el monitoreo y la gestión de servicios de seguridad en tiempo real, integrando herramientas web y móviles para una experiencia completa.

---

# Objetivos del Proyecto

* Proteger a las personas mediante servicios de seguridad confiables.
* Facilitar la comunicación inmediata entre usuarios y personal de seguridad.
* Implementar tecnologías modernas para garantizar escalabilidad y rendimiento.
* Ofrecer acceso multiplataforma mediante aplicaciones web y móviles.

---

# Tecnologías Utilizadas

## Frontend Web

* **Angular**
* **JavaScript**

El frontend web fue desarrollado utilizando Angular y JavaScript para crear una interfaz dinámica, rápida y escalable.

## Aplicación Móvil

* **Flutter**

La aplicación móvil fue desarrollada con Flutter, permitiendo compatibilidad multiplataforma tanto para Android como iOS.

## Backend

* **Node.js API**

El backend fue construido con Node.js, proporcionando una API robusta y eficiente para la comunicación entre el sistema web, la aplicación móvil y la base de datos.

## Base de Datos

* **Firebase**

Utilizamos Firebase como base de datos y plataforma de servicios en la nube para autenticación, almacenamiento y sincronización de información en tiempo real.

---

# Arquitectura del Sistema

```text
Usuarios ↔ Aplicación Web (Angular)
         ↔ Aplicación Móvil (Flutter)
         ↔ API Backend (Node.js)
         ↔ Firebase Database
```

# Instalación del Proyecto

## Clonar el repositorio

```bash
git clone https://github.com/tuusuario/soslive.git
```

## Instalar dependencias Frontend

```bash
cd frontend
npm install
```

## Ejecutar Angular

```bash
ng serve
```

## Instalar dependencias Backend

```bash
cd backend
npm install
```

## Ejecutar API Node.js

```bash
npm start
```

## Ejecutar Flutter

```bash
cd mobile
flutter pub get
flutter run
```
